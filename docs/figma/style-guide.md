# BREMSECU Figma Style Guide

Status: visual values pending approved Figma export.

## Required source
Use exported Figma tokens for:
- color palette
- lime/neon accent and glow values
- typography
- spacing scale
- corner radii
- shadows/elevation

## Rule
Do not hard-code guessed hex/font/spacing values before `design-tokens.json` is populated from the approved Figma source.

## Visual consistency
The PWA should preserve the same industrial visual language across Home, diagnostics, reports, Wi-Fi and Settings. Reusable components must use the same token set rather than per-screen styling.
