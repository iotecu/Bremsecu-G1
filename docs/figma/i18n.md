# BREMSECU G1 — Language / i18n Authority

Status: CONFIRMED from approved UI reference.

The PWA is multilingual and must support the following 14 languages in the language selector.

## Canonical language order

1. Türkçe — `tr`
2. English — `en`
3. Deutsch — `de`
4. Français — `fr`
5. Italiano — `it`
6. Ελληνικά — `el`
7. Русский — `ru`
8. العربية — `ar`
9. فارسی — `fa`
10. Български — `bg`
11. Polski — `pl`
12. Српски — `sr`
13. Română — `ro`
14. Español — `es`

## UI behavior

- The language badge in the top brand bar opens the language selector.
- The selector shows language names in their own native writing system as listed above.
- The selected language is highlighted.
- Language selection applies to the full PWA, including entry screens, main carousel, live-test screens, safety dialogs, reports, settings, validation messages and error states.
- The chosen language must persist across page reloads and device reconnects.
- Language selection must not alter diagnostic logic, pin identities, electrical thresholds or safety interlocks.
- Missing translation keys must fall back to English rather than displaying raw translation keys.

## Directionality

- Arabic (`ar`) and Persian (`fa`) require RTL text direction.
- The overall diagnostic layout should remain consistent with the approved visual system, but text alignment, flow and icon/text ordering must adapt where required for RTL readability.
- Numeric electrical values, pin numbers, units and connector identities remain unambiguous and should not be mirrored in a way that changes technical meaning.

## Agent rule

No implementation agent may reduce the supported language list, replace native labels with English-only labels, or hard-code UI strings directly into components. All user-facing strings must pass through the i18n layer.
