# Connector Assets

This directory is an index/placeholder for connector-specific artwork.

Current approved connector/socket visuals already exist in `docs/figma/assets/icons/`:
- `7638_socket_icon.png`
- `7638_cable_icon.png`
- `12098_socket_icon.png`
- `12098_cable_icon.png`

Approved full-screen connector compositions also exist under `docs/figma/screens/` and are mapped in `docs/figma/screen-inventory.md`.

Do not duplicate those binaries into this directory merely to satisfy folder structure. If a future connector asset is visually distinct from the existing socket/cable icons, place it here and document its intended screen/component usage.

Asset geometry must remain consistent with the approved visual pin maps used by the PWA.
