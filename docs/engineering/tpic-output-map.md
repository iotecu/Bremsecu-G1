# TPIC Output Map — BREMSECU G1 REV-2

Physical chain: ESP32 GPIO23 -> HCT125 -> U6 -> U5 -> U4 -> U3.

## U3
D0 OUT1 AKU-24V-1
D1 OUT2 KONTAK-24V
D2 OUT3 GND1
D3 OUT4 GND2
D4 OUT5 ABS
D5 OUT6 CANH_1_DR
D6 OUT7 CANL_1_DR
D7 OUT8 SOL-SINYAL

## U4
D0 OUT9 SAG-SINYAL
D1 OUT10 ARKA-SIS
D2 OUT11 GND3
D3 OUT12 SOL-PARK
D4 OUT13 SAG-PARK
D5 OUT14 STOP-LAMBASI
D6 OUT15 GERI-VITES
D7 OUT16 AKU-24V-2

## U5
D0 OUT17 BALATA-SINYAL
D1 OUT18 YAYLI-FREN
D2 OUT19 ASANSOR-DINGIL
D3 OUT20 GND4
D4 OUT21 CANH_2_DR
D5 OUT22 CANL_2_DR
D6 NC
D7 NC

## U6 relay/control
D0 K4 CAN7638_RELAY_DR
D1 K5 CAN12098_RELAY_DR
D2 NC
D3 NC
D4 K3 CAN12098_RELAY_CK
D5 K2 CAN7638_RELAY_CK
D6 K1 SELECT_V_RELAY
D7 K6 MASTER_GND_RELAY

## Safe boot
Firmware must hold outputs disabled, shift 32 zeros, latch the zero word, then enable outputs. Physical output mapping was verified during REV-2 bring-up.
