2. 3.3V -> 5V LOGIC BUFFER
===========================

Reference: U7 MC74HCT125ADTR2G
Supply: 5V
GND: GND
All OE pins are tied low / enabled.

Input (3.3V side) | Buffer Channel | Output (5V side)
------------------|----------------|------------------
SER_IN            | A1 -> Y1       | TPIC_SER
CLK_IN            | A2 -> Y2       | TPIC_CLK
RCK_IN            | A3 -> Y3       | TPIC_RCK
OE_IN             | A4 -> Y4       | TPIC_G#

OE_IN has a 10k pull-up to 3.3V.
MCU GPIO13 reaches OE_IN through RU23 = 220R.


3. TPIC DAISY CHAIN / OUTPUT MAP
================================

Devices: U3, U4, U5, U6 = TPIC6B595DWR
Supply: 5V
Shared SRCK = TPIC_CLK
Shared RCK  = TPIC_RCK
Shared G#   = TPIC_G#
SRCLR# is pulled up to 5V through 10k.

Daisy-chain order:
U6 -> U5 -> U4 -> U3

Confirmed serial connections:
U3 SER IN = U4 SER OUT
U4 SER IN = U5 SER OUT
U5 SER IN = U6 SER OUT
U6 SER IN = TPIC_SER

IMPORTANT:
U6 SER IN = TPIC_SER is confirmed from the schematic.

TPIC serial-data chain:
MCU SER_IN -> HCT buffer -> TPIC_SER -> U6 SER IN -> U6 SER OUT -> U5 SER IN
-> U5 SER OUT -> U4 SER IN -> U4 SER OUT -> U3 SER IN

Shared clock/control nets:
SRCK = TPIC_CLK
RCK  = TPIC_RCK
G#   = TPIC_G#

7. RELAY CONTROL MAP
====================

Relay | Control Net          | Function
------|----------------------|---------------------------------------------
K1    | SELECT_V_RELAY       | SELECT_V source selection
K2    | CAN7638_RELAY_CK     | ISO7638 truck-side CAN selection
K3    | CAN12098_RELAY_CK    | ISO12098 truck-side CAN selection
K4    | CAN7638_RELAY_DR     | ISO7638 trailer-side CAN selection
K5    | CAN12098_RELAY_DR    | ISO12098 trailer-side CAN selection
K6    | MASTER_GND_RELAY     | MASTER_GND connection control

SELECT_V relay:
- Selects the required test source for SELECT_V.
- 3.3V and 24V are the two switched source rails shown in the schematic.

CAN relay selected measurement nets:
ISO7638  -> CANH_1_R / CANL_1_R
ISO12098 -> CANH_2_R / CANL_2_R

Firmware safety rule:
For the same CAN standard, truck-side and trailer-side selector relays must not be energized
simultaneously.


8. CAN TERMINATION / MEASUREMENT REFERENCE
==========================================

ISO7638 selected pair:
CANH_1_R
CANL_1_R

ISO12098 selected pair:
CANH_2_R
CANL_2_R

Termination-test principle:
3.3V -> 1.5k -> CAN-H selected node
CAN-L selected node -> 1.5k -> GND

Selected CAN nodes are also routed to the ADC/MUX measurement system.

Critical firmware interlock:
Before a CAN termination test, all relevant ISO7638 / ISO12098 voltage channels must be checked.
If battery, ignition or any unexpected external energy is detected:
- abort termination test
- do not energize CAN termination / selection relays
- report that the line is energized and termination test cannot start

Only after the relevant lines are verified de-energized may the resistance/termination test proceed.

11. INA226 CURRENT MEASUREMENT MODULE
====================================

Reference: MDL1 / CJMCU-226 style module

Pin | Module Function | Net / Role
----|-----------------|----------------------------
1   | VCC             | 3.3V
2   | GND             | GND
3   | SDA             | SDA
4   | SCL             | SCL
5   | ALERT           | NC
6   | VBS             | 24V load-side sense, tied to Pin 7
7   | IN-             | 24V_LOAD_SIDE
8   | IN+             | 24V_SOURCE_SIDE

Current path:
24V_SOURCE -> IN+ -> SHUNT -> IN- -> 24V distribution / load side

Normal load current is intended to be measured in the positive direction.

INA226 shares the I2C bus:
SDA -> GPIO21
SCL -> GPIO22

Note:
The INA226 I2C address is determined by the module's A0/A1 hardware configuration.
This is a firmware configuration parameter and must match the physical module used.

14. FIRMWARE SAFETY / IMPLEMENTATION FLAGS
==========================================

- NC / UNUSED MUX channels must never be treated as valid measurement channels.
- U5 DRAIN6 and DRAIN7 are unused.
- U6 DRAIN2 and DRAIN3 are unused.
- CAN termination testing is permitted only on a verified de-energized line.
- Truck-side and trailer-side CAN selection relays for the same standard must not be active together.
- MASTER_GND control must be handled as a deliberate test function, not a default permanent connection.
- ASANSOR-DINGIL is a controlled output intended for axle-lift testing under valid pneumatic conditions.
- Pulse inputs are read digitally through the CD40106 while the corresponding signal lines may also be measured through the analog measurement system.
- Current measurement is used to validate load operation and identify abnormal current / short-circuit conditions.
- This file defines hardware mapping only. Test thresholds, delays, diagnostic correlation rules,
  report logic and PWA workflow belong in the engineering Markdown specifications.
